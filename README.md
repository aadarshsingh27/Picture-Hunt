# 🖼️ Picture Hunt - Premium Image Experience

**Picture Hunt** is a modern **React-powered** application featuring smooth **GSAP animations** and a premium glassmorphic design. Explore millions of high-quality images with a fluid and highly responsive interface.

## ✨ Features

- **⚛️ React Architecture**: Built using React for efficient state management and high performance.
- **🎭 GSAP Animations**: Professional entrance animations, staggered grid reveals, and micro-interactions.
- **🔍 Dynamic Search**: Real-time image searching powered by the Unsplash API.
- **📥 Direct Downloads**: Quickly download images in high resolution with one click.
- **🙈 Animated Hide**: Remove images from your view with smooth scale-down transitions.
- **🎨 Glassmorphic UI**: Elegant dark theme with blurred backdrops and vibrant gradients.
- **📱 Responsive Design**: Fully optimized for a seamless experience on every device size.

## 🛠️ Tech Stack

- **Framework**: React 18 (via CDN)
- **Animations**: GSAP (GreenSock Animation Platform)
- **Styling**: Modern CSS3 with Glassmorphism & Outfit Typography
- **Transpilation**: Babel (In-browser)
- **API**: [Unsplash API](https://unsplash.com/developers)

## 🚀 Getting Started

### Prerequisites

You will need an Unsplash API Access Key. You can get one by creating a developer account at [Unsplash Developers](https://unsplash.com/developers).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aadarshsingh27/Picture-Hunt.git
   ```

2. Open the project directory:
   ```bash
   cd Picture-Hunt
   ```

3. Open `index.html` and replace the placeholder API key with your own inside the `<script>` tag:
   ```javascript
   const ACCESS_KEY = "YOUR_UNSPLASH_ACCESS_KEY";
   ```

4. Launch the application:
   Simply open `index.html` in your favorite web browser.
